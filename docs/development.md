# CivicLens Local Development Guide

## Prerequisites

- Node.js >= 20
- PNPM >= 9

## Running the Application

You can use standard `npm` or `npx pnpm`:

```bash
# Using standard npm (recommended for Windows)
npm run dev:web      # Starts Public Web App on http://localhost:3000
npm run dev:admin    # Starts Admin CMS Panel on http://localhost:3002
npm run dev:api      # Starts REST API Server on http://localhost:3001

# Or using npx pnpm:
npx pnpm dev:web
```
