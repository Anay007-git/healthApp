# CivicLens Evidence Traceability Model

Every public stat on CivicLens must be verifiable down to its primary source:

```text
Statistic Shown
       ↓
Claim Entry
       ↓
Evidence Summary
       ↓
Source Document Ref (e.g. Budget 2024-25, Page 142)
       ↓
Verification Drawer
```

## Verification Workflow

1. `DRAFT`: Entry created by analyst with source link.
2. `REVIEW`: Reviewer checks document page ref and verification methodology.
3. `VERIFIED`: Passed audit check.
4. `PUBLISHED`: Made visible on public platform and AI engine knowledge base.
